## 🚀 Projects I'm Proud Of

### 🛰️ Huawei Tracker
**Internal project tracking system for network rollout operations**  
`Spring Boot` `Angular` `MongoDB` `JWT` `Docker`

Built for the IAM NPM team to manage complex telecom projects. Handles team permissions, progress reporting, and multi-level project hierarchies. Learned a ton about enterprise-scale auth and real-world data modeling.

---

### 🎥 Stadium Violence Detection System
**Real-time CCTV analysis with instant alerts**  
`Python` `YOLOv8` `LSTM` `RabbitMQ` `Angular` `Spring Boot` `Docker`

Trained YOLOv8 on custom violence datasets, built an event processing pipeline with RabbitMQ, and created a dashboard for security teams. The system detects violent behavior in stadium footage and triggers notifications in real-time. This was my first dive into production ML systems.

---

### 📊 Dynamic Reporting Platform
**Flexible MongoDB reporting without schema hell**  
`Spring Boot` `MongoDB` `Embedded templates` `Dynamic aggregations`

Admins design report structures through a UI, users generate complex reports without needing devs to write queries or run migrations. Supports nested data, custom filters, and export to multiple formats. Solved a real pain point for teams drowning in ad-hoc report requests.
