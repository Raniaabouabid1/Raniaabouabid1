## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" width="30" /> Projects That Actually Ship

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Satellite.png" width="25" /> Huawei Tracker
**Internal project tracking system for telecom network rollouts**  
`Spring Boot` `Angular` `MongoDB` `JWT` `Docker`

Built for Huawei's IAM NPM team to wrangle hundreds of network deployment projects. Features multi-level permissions, progress tracking, automated reporting, and a dashboard that doesn't make project managers cry. Learned a ton about enterprise auth, data modeling at scale, and why soft deletes exist.

**The challenge:** Different teams needed different views of the same data, with strict access control.  
**The solution:** Flexible role-based system with dynamic filtering and aggregated views.

---

### <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Video%20Camera.png" width="25" /> Stadium Violence Detection System
**Real-time CCTV analysis with instant alerts**  
`Python` `YOLOv8` `LSTM` `RabbitMQ` `Angular` `Spring Boot` `Docker`

Trained YOLOv8 on custom violence datasets, built an event processing pipeline, and created a dashboard for security teams. The system watches stadium footage in real-time, detects violent behavior (fights, crowd surges, weapons), and triggers notifications before things escalate.

**The challenge:** Process 4+ camera feeds simultaneously with <1s latency.  
**The solution:** Distributed processing with RabbitMQ, optimized model inference, and smart event batching.

**What I learned:** Production ML is 20% training models, 80% handling edge cases and keeping things running.
